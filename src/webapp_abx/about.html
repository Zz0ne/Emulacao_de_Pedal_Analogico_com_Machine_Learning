Finalidade

Este site é um protótipo client-side do teste ABX duplo-cego que integra o projeto final de licenciatura em Engenharia Informática. O projeto final desenvolve um plugin de áudio que emula, por Machine Learning, o pedal de distorção Darkglass Alpha Omicron. A validação percetual dessa emulação exige um teste ABX com participantes humanos. Aproveitei o enunciado deste e-fólio para prototipar toda a interface e lógica de teste em HTML, CSS e JavaScript puros.

Organização lógica

O site tem cinco páginas interligadas. A index.html funciona como menu de distribuição, com cards apontando para as secções. A project.html dá contexto sobre o projeto final e a metodologia black-box. A instructions.html explica o método ABX e o significado estatístico dos resultados. A test.html é o motor do teste, com três ecrãs (intro, trial, conclusão) controlados por JavaScript. A results.html apresenta a análise da última sessão. Esta página — about.html — é o relatório exigido pelo enunciado.

Separação de conteúdo e apresentação

Todo o estilo vive em três ficheiros CSS: base.css com variáveis, reset e tipografia; layout.css com a estrutura partilhada; e components.css com peças específicas (cards, botões, componentes do teste ABX). O HTML é semântico (<header>, <nav>, <main>, <section>, <footer>). As cores são todas definidas por variáveis CSS num único bloco :root, o que tornaria trivial implementar um tema alternativo sem tocar numa linha de HTML. A estrutura modular permite mudar completamente a apresentação alterando apenas CSS.

Funcionalidades dinâmicas

Foram implementadas quatro funcionalidades dinâmicas. Primeira: o motor do teste ABX, que gera doze trials com X aleatorizado, controla transições entre ecrãs e persiste o estado no localStorage, permitindo retomar uma sessão interrompida. Segunda: a síntese de áudio em tempo real via Web Audio API, que gera sinais de baixo distorcido com duas variantes (hardware e emulação) matematicamente próximas mas perceptivelmente distintas. Terceira: a barra de progresso, renderizada dinamicamente em JavaScript conforme o utilizador avança nos trials. Quarta: a análise estatística na página de resultados, com cálculo do p-value por distribuição binomial, d-prime por inversa da CDF normal, animação CSS da barra de performance e renderização de pills coloridas por trial.
